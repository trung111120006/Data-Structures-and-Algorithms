# C++ Data Structures & Algorithms (DSA)

A repository for self-studying, practicing, and archiving **C++** solutions to Data Structures & Algorithms problems from competitive programming and coding platforms such as LeetCode.

## Key Topics

- **Algorithmic Complexity**: Time Complexity and Space Complexity analysis.
- **Arrays, Strings, Two Pointers & Sliding Window** (`arrays-strings-pointers/`).
- **Recursion & Backtracking** (`recursion-backtracking/`).
- **Searching & Sorting** (`searching-sorting/`).
- **Linked Lists, Stacks, Queues & Heaps / Priority Queues** (`linked-list-stack-queue-heap/`).
- **Trees (Binary Tree, BST, Segment Tree, Fenwick Tree...)** (`trees/`).
- **Graphs (BFS, DFS, Dijkstra, Floyd, MST, DSU...)** (`graphs/`).
- **Dynamic Programming** (`dp/`).
